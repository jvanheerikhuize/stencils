# Stencils

Configured and sliced 3D-printable stencil files generated by the [OpenSCAD Stencil Generator](https://github.com/jvanheerikhuize/openSCAD/blob/main/Stencil%20Generator/stencil_generator.scad).

The stencil generator converts SVG artwork into stencil plates with beveled edges, handles, and registration marks for spray-painting alignment.

## Repository structure

Each stencil project lives in its own directory containing:

- Source SVG artwork
- OpenSCAD configuration (`.scad`) referencing the generator
- Exported STL model(s)
- Sliced print file(s) (`.gcode`, `.3mf`, etc.)
